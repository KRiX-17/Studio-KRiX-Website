## Resident Advisor artist credits

A website link to an RA event does not automatically associate KRiX with that event's artist identity. Only an authorised event editor can apply the artist tag. Verify the updated event and artist page before marking an entry complete.

## Add another show

Update `data/live-events.ts` with the verified date, venue, source URL and event artwork. An `endsAt` timestamp with an explicit time-zone offset is useful for club nights that finish after midnight. The Music page then automatically moves the event from Upcoming to Past. The current system does not submit or alter events on Resident Advisor.

## Media to add later

- A high-quality genuine live-performance photograph with usage permission
- A publicly accessible, verified KRiX DJ mix URL (not a third-party playlist)
- Optional press portrait, transparent KRiX logo and short technical rider

The online EPK uses genuine event posters until those assets are available. No stock imagery is presented as a KRiX performance.

## Analytics and privacy

The current privacy policy explicitly says no analytics are running. Do not silently introduce click trackers or a new service. If privacy-conscious first-party analytics are approved later, update the policy and explain provider, purposes, retention and consent obligations before enabling event counts. Prioritise aggregated booking-click and RA-link metrics over visitor tracking.
